# AI Engineering Templates

Reusable Markdown templates for planning, implementing, testing, reviewing, documenting, and releasing software projects.

## Usage

- Copy the relevant template into a project or task document.
- Fill only the sections relevant to the work.
- Replace placeholders in angle brackets, for example `<Project Name>`.
- Do not invent missing technical or product information; mark it as `TODO` or ask for clarification.
- Follow the shared rules in `../rules/`, especially `00-ai-operating-rules.md`.

## Templates

- `project-context-template.md`: Create project-specific AI instructions.
- `feature-spec-template.md`: Define a feature before implementation.
- `bug-fix-template.md`: Investigate and fix a bug safely.
- `ai-task-prompt-template.md`: Give an AI coding agent a precise task.
- `pull-request-template.md`: Prepare a clear pull request description.
- `adr-template.md`: Record an important architecture decision.
- `readme-template.md`: Create accurate project documentation.
