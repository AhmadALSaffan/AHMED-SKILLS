# Ahmad Skill for Claude Code

Install this folder as a Claude Code skill to use commands such as:

```text
/ahmed-skill init
/ahmed-skill design
/ahmed-skill feature
/ahmed-skill review
/ahmed-skill readme
/ahmed-skill status
```

## Install globally

Copy the `ahmed-skill` folder to:

```text
~/.claude/skills/ahmed-skill/
```

## Install for one project

Copy the `ahmed-skill` folder to:

```text
<your-project>/.claude/skills/ahmed-skill/
```

The skill contains `SKILL.md` plus support references for project initialization, design discovery, and README style.
