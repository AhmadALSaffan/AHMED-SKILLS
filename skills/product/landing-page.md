# Landing Page Development

## Purpose

Use this skill file only when the task is relevant to product landing page development. Follow the shared engineering rules first, especially security, code quality, testing, documentation, and AI operating rules.

## AI Workflow

1. Inspect the repository, existing conventions, dependencies, build configuration, tests, and relevant source files.
2. Identify the smallest safe change that satisfies the task.
3. Reuse existing project patterns when they are clear and appropriate.
4. Add or update tests for changed behavior when practical.
5. Run the relevant formatter, lint, tests, and build commands.
6. Report changed files, verification performed, assumptions, limitations, and required manual steps.

## AI Must Do

- Identify the target audience, primary conversion goal, value proposition, and call to action before implementation.
- Create a clear hero section that explains what the product is, who it is for, and why it matters.
- Structure content around verified benefits, features, proof, objections, FAQs, and conversion actions.
- Use consistent visual hierarchy, responsive layout, accessible semantics, readable typography, and fast-loading assets.
- Add analytics events only when the analytics setup and event definitions are verified.
- Optimize page metadata, social preview metadata, semantic headings, and performance where relevant.
- Use real screenshots, testimonials, metrics, prices, logos, and claims only when verified and approved.

## AI Must Not Do

- Do not invent testimonials, customer logos, user counts, performance claims, pricing, guarantees, integrations, or legal claims.
- Do not use deceptive urgency, dark patterns, inaccessible forms, or misleading calls to action.
- Do not expose private keys or backend secrets in the frontend.
- Do not sacrifice mobile usability or performance for decorative effects.

## Verification Checklist

- Confirm the primary value proposition and CTA are visible without scrolling on common screens where appropriate.
- Confirm forms validate input and provide accessible feedback.
- Confirm mobile layout, keyboard access, metadata, and performance are verified.
- Confirm all public claims, links, screenshots, and prices are real and approved.
