# AI Engineering Rules

This folder contains modular instructions for AI coding assistants.

## Usage

- Always load `00-ai-operating-rules.md`.
- Load the rules relevant to the current task.
- Apply explicit user instructions, security, and safety requirements before general rules.
- Project-specific rules may override these general rules when they do not conflict with explicit user instructions, security, or safety.

## Files

Each numbered file covers one engineering topic. Numeric prefixes provide a stable reading order.
